# Olympic-Swimming-Prediction-2028
Machine learning-based analysis and prediction of Olympic swimming performances from 1912 to 2028 using Python and Streamlit.

# Olympic Swimming: History and 2028 Predictions

## Project Overview

This project analyzes historical Olympic swimming performances from 1912 to 2024 and predicts the best recorded swimming times for the 2028 Olympic Games using machine learning.

## Features

- Filter swimming events by gender, distance, stroke, and country.
- Visualize historical swimming performance trends.
- Compare multiple countries on interactive graphs.
- Compare four machine learning regression models.
- Select the model with the lowest historical Mean Absolute Percentage Error (MAPE).
- Predict swimming performance for the 2028 Olympics.

## Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Plotly
- Visual Studio Code

## Machine Learning Algorithms

1. Linear Regression
2. Ridge Regression
3. Random Forest Regression
4. Gradient Boosting Regression

## How to Run the Project

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

Start the Streamlit application:

```bash
python -m streamlit run app.py
```

Open http://localhost:8501 in your browser.

## Dataset

Olympic swimming results from 1912 to 2024.

Reference: https://www.olympics.com/en/olympic-games/olympic-results
